# Key Projects

## SQL Error Detection & Auto-Remediation Agent
**Role**: Creator / AI Engineer
**Tech Stack**: Agentic AI, Python, SQL, FastAPI
**Description**: Built a multi-step agent that autonomously handles data pipeline failures.
**Features**:
- Parses ETL/job logs to classify failure types (schema drift, null constraints, type mismatch).
- Generates deterministic remediation SQL.
- Validates fixes in a sandbox environment.
- Outputs an audit-ready report with root cause, SQL diff, and evidence.
**Impact**: Reduced manual debugging time by **50%**.

## Data Governance Knowledge Worker (RAG)
**Role**: Creator
**Tech Stack**: RAG (Retrieval Augmented Generation), Vectors, Embeddings
**Description**: Built a retrieval system to answer stakeholder questions using grounded citations from policy/procedure docs and data definitions.
**Features**:
- Implements chunking, embeddings, and indexing.
- Uses confidence flags to support accuracy and governance reviews.
- Strict citation of policy documents.
